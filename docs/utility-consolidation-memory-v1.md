# 效用巩固记忆 v1：固定容量的历史最小原型

> 本文及其推广版[效用巩固记忆 v2](utility-consolidation-memory-v2.zh.md)均为当前暂停的历史研究，不进入从零训练的 GDN＋GQA Base。本文的固定每条容量、最低预测效用淘汰是 v2 在 $R_{\max}=1,C=S,\lambda=0$ 时的严格特例。

> 版本：v1.0
>
> 状态：核心公式已冻结，允许实现；具体维度和训练日程仍待小规模实验确定。
>
> 目标：在固定状态预算下，学习删除哪一条长期记录对决策后的未来伤害最小。
>
> 范围：本文冻结记忆管理机制，不冻结完整 1B 主干配置。

## 1. 设计原则

第一版只保留以下机制：

1. 最近事件先进入固定延迟缓冲；
2. 每次只有一个候选进入长期记忆竞争；
3. 训练期使用决策之后的反事实未来损失生成效用标签；
4. 推理期由效用预测器打分；
5. 长期记忆已满时只淘汰一条记录；
6. 记录保持独立、不可变，不合并、不插值；
7. 模型通过标准 Cross-Attention 读取长期记忆。

第一版不使用显式年龄、occupancy、新奇度、surprise、指数衰减、冲突门、关联图、soft write 或可微 Top-K。

## 2. 符号与时间线

- $M_t$：决策时刻 $t$ 之前的长期记录集合；
- $S$：长期记忆容量；
- $c_t$：经过固定等待期 $D$ 后进入巩固决策的单个候选；
- $B_t$：决策时已经观察到、且仍位于短期缓冲中的近期上下文；
- $g_t$：当前任务目标表示；
- $Y_t=x_{t+1:t+F}$：决策之后长度为 $F$ 的训练评价区间；
- $m_i$：具有稳定 event ID、slot ID 和时间信息的不可变事件记录。

每个候选在事件发生后的第 $D$ 个调度点参与巩固。预测器只能读取决策时已经观察到的信息； $Y_t$ 仅用于训练期构造监督标签。

## 3. 冻结的核心公式

### 3.1 候选进入

$$
\boxed{
\mathcal R_t=M_t\cup\lbrace c_t\rbrace
}
$$

并且：

$$
|\mathcal R_t|\le S+1.
$$

如果同一调度点产生多个候选，必须按照确定的时间顺序逐个处理，每次决策后重新计算下一次分数。

### 3.2 训练期反事实未来效用

使用固定或缓慢 EMA 更新的标签生成模型 $\bar\theta$：

$$
\boxed{
u_{t,i} =
\mathcal L_{\bar\theta,F}
\left(
Y_t\mid B_t,\mathrm{mask}_i(\mathcal R_t)
\right) -
\mathcal L_{\bar\theta,F}
\left(
Y_t\mid B_t,\mathcal R_t
\right)
}
$$

其中 $\mathrm{mask}_i$ 只改变记录 $m_i$ 的可见性，不重排其他记录的位置。解释如下：

- $u_{t,i}\gt 0$：删除 $m_i$ 增加未来损失，应倾向保留；
- $u_{t,i}\approx0$：删除基本无影响；
- $u_{t,i}\lt 0$：删除反而降低未来损失，应优先淘汰。

训练损失可先使用未来 token 或监督答案损失：

$$
\mathcal L_{\bar\theta,F} =
\sum_{\tau=1}^{F}\ell_{t+\tau}.
$$

第一批实验取 $\gamma=1$，不预设远端信息应按时间折扣。

### 3.3 效用预测

$$
\boxed{
\hat u_{t,i} =
f_\phi
\left(
m_i,g_t,B_t,\mathcal R_t
\right)
}
$$

预测器通过直接回归监督训练：

$$
\boxed{
\mathcal L_{\mathrm{utility}} =
\sum_i
\left(
\hat u_{t,i}
-\mathrm{stopgrad}(u_{t,i})
\right)^2
}
$$

平方误差下的总体最优预测为条件均值：

$$
f^*(m_i,I_t) =
\mathbb E[u_{t,i}\mid m_i,I_t],
\qquad
I_t=(g_t,B_t,\mathcal R_t).
$$

因此预测器的职责不是准确预知唯一未来，而是估计删除各记录造成的期望未来损失。

### 3.4 单次淘汰

如果：

$$
|\mathcal R_t|\le S,
$$

则：

$$
M_{t+1}=\mathcal R_t.
$$

否则：

$$
\boxed{
M_{t+1} =
\mathcal R_t
\setminus
\left\lbrace 
\arg\min_i\hat u_{t,i}
\right\rbrace
}
$$

精确效用下：

$$
\arg\min_i u_{t,i} =
\arg\min_i
\mathcal L_{\bar\theta,F}
\left(
Y_t\mid B_t,
\mathcal R_t\setminus\lbrace m_i\rbrace
\right),
$$

因为完整集合损失对所有候选相同。这个结论只保证当前单次淘汰最优；连续多次淘汰仍然是需要重新评分的贪心过程。

## 4. 标准读取接口

长期记忆通过标准 Cross-Attention 进入主干：

$$
Q=HW_Q,\qquad K=M_tW_K,\qquad V=M_tW_V,
$$

$$
\boxed{
H' =
H+
\mathrm{softmax}
\left(
\frac{QK^\top}{\sqrt{d_m}}
\right)
VW_O
}
$$

完成一个 chunk 后产生的候选，只能影响之后的 token，不能回写并重新计算当前 chunk 中更早的 token。

## 5. 训练与推理

### 5.1 训练

训练额外执行反事实标签生成：

1. 先训练 Reader 能够使用记忆；
2. 冻结或使用 EMA Reader/事件编码器作为 $\bar\theta$；
3. 对同一竞争集合执行完整分支和 mask 分支；
4. 生成 $u_{t,i}$；
5. 通过 $\mathcal L_{\mathrm{utility}}$ 训练 $f_\phi$；
6. Reader 继续由语言模型或任务损失训练。

Hard eviction 不参与普通反向传播。系统不是通过离散选择端到端可微训练；效用预测器依靠直接反事实监督。

若 $|\mathcal R_t|=S+1$，精确计算全部标签需要一次完整集合评估和 $S+1$ 次 mask 评估。训练早期必须比较：

- 全量标签；
- 每次随机采样少量记录；
- 离线标签缓存；
- 周期性刷新标签。

### 5.2 推理

推理阶段不访问未来区间，不计算反事实分支。每次候选到期只执行：

1. 对 $\mathcal R_t$ 中的记录预测 $\hat u_{t,i}$；
2. 若超出容量，删除预测效用最低的一条；
3. 后续 token 通过 Cross-Attention 读取更新后的 $M_{t+1}$。

## 6. 相对传统 Transformer 的假设优势

### 6.1 状态规模

全上下文 Transformer 的 KV 状态随总历史长度 $T$ 增长：

$$
O(Td).
$$

本结构使用局部窗口 $W$ 和长期容量 $S$：

$$
O((W+S)d),
$$

在固定 $W,S$ 时与任务总长度无关。

### 6.2 超出局部窗口后的选择性保留

滑动窗口 Transformer 按时间淘汰：

$$
C_t=x_{t-W+1:t}.
$$

本结构按预测未来删除成本淘汰，因此可能保留很老但仍有价值的记录，并丢弃较新但无用的记录。

### 6.3 显式修订

普通 KV cache 追加历史但不直接删除已失效状态。本结构允许旧记录在新候选到来时通过效用竞争被明确淘汰。该优势是待验证的归纳偏置，不是 Transformer 表达能力上的不可能性结论。

### 6.4 代价与劣势

- 在历史仍位于完整上下文时，Full Attention 通常具有更完整的逐 token 证据；
- 一旦错误淘汰且原文不可恢复，信息永久丢失；
- 反事实标签使训练显著变贵；
- 记忆决策引入跨 chunk 的顺序依赖，训练并行性弱于普通 Transformer。

## 7. 相对线性注意力或递归状态模型的假设优势

KDA、RWKV 等方法把历史持续压入固定矩阵或递归状态。其主要优势是固定状态和高效逐 token 推理。本结构不试图在纯吞吐上击败它们，而是假设在以下场景具有优势：

1. 重要信息稀疏分布在很长的任务轨迹中；
2. 历史事件需要保持独立身份；
3. 需要单独删除、检查或消融某条事件；
4. 新旧状态频繁覆盖，连续状态容易发生干扰；
5. 未来用途可以从目标和近期上下文中预测。

线性注意力通常具有更低、更平滑的推理成本；本结构每个 token 读取 $S$ 条记录，代价近似：

$$
O(Sd_m),
$$

候选巩固还需额外评分。若每条历史信息都很重要、未来用途高度不可预测，或者任务主要是密集 token 依赖，线性注意力或 Full Attention 可能更合适。

## 8. 复杂度摘要

| 项目 | Full Attention | 线性/递归注意力 | 本结构 |
|---|---:|---:|---:|
| 总历史状态 | $O(Td)$ | 固定 | $O((W+S)d)$ |
| 单 token 长期读取 | $O(Td)$ | 近似固定 | $O(Sd_m)$ |
| 历史逐条可寻址 | 是 | 通常否 | 是，仅限保留记录 |
| 显式单条淘汰 | KV 通常不做 | 困难 | 核心操作 |
| 训练并行性 | 强 | 强或可扫描 | 较弱 |
| 额外训练成本 | 低 | 中 | 高，来自反事实标签 |
| 主要失败模式 | KV 增长、长上下文干扰 | 状态压缩干扰 | 错误淘汰、标签成本 |

## 9. 第一批实验

固定 $S=32$，固定大小不可变事件记录，一次处理一个候选。比较：

1. FIFO：相同总状态预算；
2. 随机淘汰；
3. 预测效用淘汰；
4. 决策后未来信息 Oracle 单次淘汰；
5. Full Attention 或足够长上下文上界；
6. 一个线性/递归状态基线。

必须同时报告短期缓冲和长期记录的总状态预算。主要指标：

- 长距离召回；
- 多次状态覆盖后的旧值误用率；
- 随任务长度增长的成功率；
- 选择 regret；
- 训练 FLOPs；
- 推理延迟、吞吐和峰值显存。

诊断规则：

- Oracle 也无收益：优先检查记录表示、Reader 或未来损失定义；
- Oracle 有收益但预测策略无收益：优先检查效用预测器和训练分布；
- 预测策略有效但成本过高：再研究标签采样、蒸馏和更新频率。

## 10. 当前研究主张

第一版不主张全面优于 Transformer 或线性注意力。待验证主张是：

> 在固定状态预算、长任务、关键事件稀疏且状态会被多次覆盖的条件下，使用决策后反事实未来损失训练的单次淘汰策略，能够比按时间淘汰和连续压缩状态更可靠地保留未来有用的信息。
