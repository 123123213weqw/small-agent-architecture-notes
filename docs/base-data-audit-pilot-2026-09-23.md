# 基础预训练数据审计：第一轮随机样本（2026-09-23）

> 状态：**仅完成可读取性与自动指标初筛；四个来源均未批准训练。** 没有下载全集，也没有修改 L40/JFS 的训练目录。原文样本与逐行指标保存在本机非 Git 输出目录；仓库只提交脚本、来源清单和汇总。

## 方法和可复现性

- 用 Hugging Face Dataset Viewer 的 `rows` API，从每个来源的 `train` split 以固定种子 `20260923` 选 **20 个随机起点 × 连续 50 行**，每源 1,000 条，共 4,000 条。相邻 50 行可能相关，故不把 1,000 行误称为 1,000 个独立同分布样本。
- 记录源仓库 commit、配置、起点、总行数；本地复现脚本为 [`experiments/base_data_audit.py`](../experiments/base_data_audit.py)。只保存分析所需字段，不保存 FineWeb2-HQ 的大体积 `embeddings`。
- 此处 commit 是抽样时看到的 Hub HEAD，Dataset Viewer 请求没有显式固定 revision；正式入库必须用不可变 revision 重取/校验，不能把本轮样本当冻结训练快照。
- 自动检查字符长度、规范化后的精确哈希、重复行、粗略网页模板/邮箱模式、中文汉字占比、数学符号模式；Python 另检查 `int_score`、元数据标签及去除**已知单行标签**前后的 `ast.parse`。
- 人工快速浏览每源随机 12 条的开头，**不是**逐篇全文质量标注。所有百分比只是本轮样本内描述，不是正式入库通过率。
- 逐来源计数、分位数、观察到的 revision 和 20 个抽样起点保存在[聚合 JSON](../results/base_data_audit_pilot_20260923/summary.json)；原始文本不提交。

### Python 代码特别检查

- `int_score` 分布：1 分 91、2 分 495、3 分 347、4 分 65、5 分 2。`≥4` 仅占样本文档 **6.7%**，占样本文本字符约 **3.9%**；这不是 tokenizer 的 token 比例，也不应直接外推全库可用 token。
- **489/1,000** 条以前置 `<reponame>`、`<filename>` 或 `<gh_stars>` 标签开头。原文 `ast.parse` 通过 **484/1,000**；仅剥除已知单行标签后通过 **950/1,000**，高分子集为 **62/67**。原文语法失败大部分是包装格式，不应据此误判代码质量。
- `ast.parse` 仅表示符合当前 Python 语法；不验证运行、依赖、测试、教程价值、安全性或原仓库许可。标签清理也需保留来源字段，不能直接丢掉归属信息。
- 若坚持只用 `int_score≥4`，现有样本表明可采正文可能很少；此前设想的代码 token 目标**尚无数据支持**。下一轮应比较 3 分和 4 分的人工可用率与有效 token，而不是盲目降低阈值。

## 快速人工观察，不是总体结论

- 英文通用文本既有解释性内容，也有新闻、站点列表和主题偏离；`Edu` 标签不等于每条都适合本模型。
- 中文候选包含新闻、酒店介绍、营销/SEO 式页面和繁体语料；需要单独确认是否能提供我们想要的**高质量中文说明与技术文本**。质量分数数值很低本身不能说明差，因为尚未解释该分类器的分数校准。
- 数学候选包含论坛问答、练习题与解释，也混有单位换算页、题目列表及重复网页结构。数学符号出现不等于推导正确。
- Python 候选确有教育性代码，但也有项目碎片、生成文件和前置标签；分数不等于可直接训练。

## 已知未完成项与下一道门槛

1. **人工全文复核**：已经准备[四源各 100 条的审核索引与说明](base-data-human-review-guide.md)；逐篇标注 `接受 / 可修复 / 排除`，记录原因与抽样权重，再估计可用比例。
2. **去重与污染**：全库/跨库精确和近重复；先冻结验证集并按网站、仓库、题目族隔离；对正式评测题做重合检测。当前只完成样本内部精确哈希。
3. **许可和敏感内容**：ODC-By/CC-BY Hub 标签不是逐网页/逐仓库许可审查；Python 上游仓库许可、移除请求和真实 PII/密钥扫描均待完成。粗略高置信密钥正则在 4,000 条中未命中，但样本太小，不能当通过。
4. **分词器和规模**：还未冻结 tokenizer，因此有效 token、中文/代码/数学的 token/字节、最终混合比例都保持 `null`；也未确认技术文档来源。

**决策**：四源继续作为 `sampled` 候选，不做全集下载，不设定正式训练比例；优先解决中文质量与 Python 高分可用量两个风险，再选小模型训练子集。
