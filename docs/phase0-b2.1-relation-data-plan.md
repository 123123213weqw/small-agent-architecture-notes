# Phase 0B2.1 关系链数据增强实验计划

## 1. 问题

C 在三种子 ID 关系链任务上达到 99%–100%，但组合模板关系链平均成功率只有 16.3%。这说明当前证据更符合“无预训练字节编码器对关系表达过拟合”，尚不足以修改记忆公式或增加 Pair Utility、图网络和短期缓冲。

本实验只回答：

> 保持 C 的模型、损失、训练规模和评估集不变，只增加关系表达的训练多样性，能否修复关系链组合泛化？

## 2. 唯一实验变量

模型仍是冻结的 C：

$$
L=L_{\mathrm{reg}}+0.5L_{\mathrm{rank}}.
$$

不修改：

- 模型层数、hidden size、heads、FFN 和参数量；
- 完整集合 Set Encoder；
- 效用标签与淘汰公式；
- 训练 episode、决策组数量、batch、epoch、学习率；
- 容量、长度、hard negative 和任务比例；
- 四个测试集及 evaluation seed。

只修改训练和验证集中 `relation_chain` 的边与目标表达。八个关系模板族不复制冻结的 D/E 测试句子；其他五类任务仍使用原 A/B/C 模板。

## 3. 数据不变量

| 项目 | 当前 C | C-Relation-Data |
|---|---:|---:|
| 训练 episode | 3,000 | 3,000 |
| 训练决策组 | 36,000 | 36,000 |
| 验证 episode | 400 | 400 |
| 每测试集 episode | 600 | 600 |
| epoch | 6 | 6 |
| 数据 seed | 0 | 0 |
| evaluation seed | 0 | 0 |

生成后必须验证四个测试 JSONL 与原 Stage-1 数据逐字节哈希一致，确保没有把测试模板放进训练，也没有改变评估 episode。

## 5. 冻结门槛

数据增强判定有效需要同时满足：

1. 三种子 `test_composition/relation_chain` 平均成功率至少达到 50%；
2. 三个 Seed 的关系链成功率均不低于 35%；
3. 总组合成功率不低于当前 C 三种子均值 86% 的两个百分点以内，即至少 84%；
4. 其他五类任务中至少四类下降不超过两个百分点，且任何一类下降不超过五个百分点；
5. 四测试集平均 eviction regret 相对当前 C 增加不超过 10%；
6. 参数量和推理路径保持不变。

如果通过，保持 C 架构不变并进入 B2.2。如果失败，不根据本轮结果调模板追门槛；下一步比较子词表示或小规模语言预训练。
