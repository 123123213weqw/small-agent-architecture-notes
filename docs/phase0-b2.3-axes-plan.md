# Phase 0 B2.3-B/C 单轴外推计划

## 目的

在 B2.3-A 已确认 matched 两跳任务可从训练长度 64 外推至 512 后，分别隔离：

1. 长期记忆容量外推；
2. 关系组合深度外推。

不在同一个实验中加入额外关系干扰或改变记录类型比例。

## B2.3-B：容量

- 长度：128、256、512；
- 容量：4、8、12、16、24、32；
- 关系深度：固定两跳；
- 记录分布：matched；
- 模型种子：3、4、5；
- 每格 64 个完全配对的 episode。

预注册通过标准：所有 $S=32$ 条件、所有种子的成功率均不低于 0.95。

## B2.3-C：关系深度

- 长度：128、256；
- 容量：固定 12；
- 跳数：2、3、4、6、8；
- 干扰记录使用原始生成器的类型分布；
- 模型种子：3、4、5；
- 每格 64 个完全配对的 episode。

预注册通过标准：四跳平均成功率不低于 0.90，八跳平均成功率不低于 0.80。

所有可行条件的 Oracle 必须为 1.0，否则先判定评测器或生成器错误。
