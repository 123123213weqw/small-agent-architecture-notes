# Phase 0 B2.3-D 相似关系干扰计划

## 目标

固定已经通过的长度、容量和四跳关系条件，只增加与关键记录使用相同模板的关系边，检查效用预测器是否依赖“记录类型”捷径。

## 固定条件

- 长度 256；
- 容量 $S=12$；
- 真实链四跳；
- 每格 64 个配对 episode；
- 模型种子 3、4、5；
- 干扰数量 $K\in\{0,4,8,16,32,64\}$。

## 两类干扰

1. `disconnected`：与真实链节点完全断开的边；
2. `spoke`：每条边接触一个真实链节点，但另一端是唯一叶节点，不能形成端点间路径。

所有生成 episode 必须验证：仅由 decoy 构成的有向图中不存在目标起点到终点的路径，且 decoy 不重复真实边。

## 预注册标准

- $K=0$ 时三个种子全部成功率 1.0；
- Oracle 全部成功率 1.0；
- `disconnected/K=64` 每个种子成功率不低于 0.95；
- `spoke/K=64` 每个种子成功率不低于 0.90；
- 两类 $K=64$ 的 required recall 均不低于 0.98。
