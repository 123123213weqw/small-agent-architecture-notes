# 决策记录

## ADR-001：项目定位

- 状态：已接受
- 决策：训练约 1B 参数的小型 Agent 模型，主要覆盖工具调用、简单代码和基础数学。
- 说明：不以覆盖所有知识的通用聊天模型为第一目标。

## ADR-002：公开对比模型

- 状态：已接受
- 决策：将 TinyLlama-1.1B、OLMo-1B、Hymba-1.5B、Qwen2.5-Coder-1.5B 和 SmolLM2-1.7B 纳入横向比较。
- 说明：不同模型承担不同参照职责，不把它们视为同数据、同训练配方的严格架构实验。

## ADR-003：不训练完整传统 1B 基线

- 状态：已接受
- 决策：不为传统 Transformer 单独消耗完整 1B 预训练预算。
- 说明：最终横向能力由公开模型提供；架构归因通过小规模受控实验完成。

## ADR-004：最终架构保持开放

- 状态：已接受
- 决策：当前不在主文档中锁定任何具体的新型 Attention、状态空间模块或残差连接。
- 说明：候选结构需先提交数学定义、复杂度、参数匹配和可证伪假设，再决定是否实验。

## ADR-005：冻结效用巩固记忆 v1 的核心公式

- 状态：已接受为最小实验原型，不代表最终 1B 架构已确定。
- 决策：长期记忆采用不可变事件记录、固定延迟、单候选进入、反事实未来效用监督和单次最低效用淘汰。
- 核心：每次令 \(\mathcal R_t=M_t\cup\{c_t\}\)；容量超限时删除 \(\arg\min_i\hat u_{t,i}\)。
- 训练：效用标签只评估决策之后的未来区间；Hard eviction 不要求对离散选择反向传播。
- 明确排除：第一版不加入显式衰减、年龄、occupancy、新奇度、冲突门、关联图、soft write 或记忆合并。
- 规范：[效用巩固记忆 v1](utility-consolidation-memory-v1.md)。
