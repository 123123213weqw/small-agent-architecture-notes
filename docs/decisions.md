# 决策记录

> 当前方向改为从零训练文本专用 GDN＋GQA 混合注意力 Base；效用巩固记忆 v1/v2 与 B2 编码选择器均为暂停的历史研究，见 ADR-012。以下旧 ADR 保留原始决策脉络，不代表当前训练结构。

## ADR-001：项目定位

- 状态：已接受
- 决策：训练约 1B 参数的小型 Agent 模型，主要覆盖工具调用、简单代码、基础数学和固定状态预算下的长任务状态保持。
- 说明：不以覆盖所有知识的通用聊天模型为第一目标。

## ADR-002：公开对比模型

- 状态：已接受
- 决策：将 TinyLlama-1.1B、OLMo-1B、RWKV-7、Kimi Linear/KDA、Hymba-1.5B、Qwen2.5-Coder-1.5B 和 SmolLM2-1.7B 纳入架构或能力参考。
- 说明：不同模型承担不同参照职责，不把它们视为同数据、同训练配方的严格架构实验。

## ADR-003：不训练完整传统 1B 基线

- 状态：已接受
- 决策：不为传统 Transformer 单独消耗完整 1B 预训练预算。
- 说明：最终横向能力由公开模型提供；架构归因通过小规模受控实验完成。

## ADR-004：最终架构保持开放

- 状态：已修订
- 决策：效用巩固记忆 v1 冻结为最小实验原型，随后推广为 v2；完整 1B 主干仍不锁定深度、宽度或数值配置。
- 说明：冻结记忆管理公式不等于最终架构已确定。主干由分阶段受控实验决定。

## ADR-005：冻结效用巩固记忆 v1 的核心公式

- 状态：历史最小实验原型；v2 将固定每条容量推广为可变 $r_i$，本 ADR 作为严格特例保留。
- 决策：长期记忆采用不可变事件记录、固定延迟、单候选进入、反事实未来效用监督和单次最低效用淘汰。
- 核心：每次令 $\mathcal R_t=M_t\cup\lbrace c_t\rbrace$；容量超限时删除 $\arg\min_i\hat u_{t,i}$。
- 训练：效用标签只评估决策之后的未来区间；Hard eviction 不要求对离散选择反向传播。
- 明确排除：第一版不加入显式衰减、年龄、occupancy、新奇度、冲突门、关联图、soft write 或记忆合并。
- 规范：[效用巩固记忆 v1](utility-consolidation-memory-v1.md)。

## ADR-006：单候选、单淘汰和不可变记录

- 状态：已接受
- 决策：每个 consolidation step 只加入一个候选；长期记忆满时最多淘汰一条；多个候选按照确定的时间顺序逐个处理并重新评分。
- 决策：记录具有稳定 event ID、slot ID 和时间信息；第一版选中时原样保留，淘汰时整体移除，不执行插值、合并或重写。
- 说明：该限制使反事实 mask 只改变一条记录的可见性，并让精确效用对应当前单次淘汰的未来损失。

## ADR-007：训练与推理解耦

- 状态：已接受
- 训练：使用固定或 EMA Reader/事件编码器生成决策后未来区间的反事实效用标签，Utility Predictor 通过直接回归学习；不声称梯度穿过 Hard eviction 端到端训练整个系统。
- 推理：不访问未来、不执行反事实分支和反向传播；只预测效用、执行单次淘汰并通过标准 Cross-Attention 读取保留记录。

## ADR-008：阶段性停止条件

- 状态：已接受
- 决策：Future Oracle 在相同总状态预算下不能超过 FIFO 时，停止扩展该记忆方向。
- 决策：只有预测效用策略能接近 Oracle，并在受控实验中超过 FIFO 和连续状态基线时，才扩展到 300M–400M 及最终约 1B。

## 待决策事项

1. 参数预算按总参数、非 Embedding 参数还是训练 FLOPs 主匹配；

3. 局部窗口 $W$、长期条数 $S$、向量预算 $C$、每条上限 $R_{\max}$、等待期 $D$ 和监督区间 $F$ 的数值；
4. 事件记录的粒度、编码维度和保留原文的具体存储方式；
5. Utility Predictor 的具体层数、标签采样率和教师更新日程；
6. 中英代码 Tokenizer 的词表规模；
7. Agent 消息格式和工具 Schema；
8. 最终训练数据混合与 token 预算。

## ADR-009：Phase 0A/0B 先采用符号 Reader

- 状态：第一轮实验已完成，0A 和 0B 均通过；结论限于符号环境。
- 决策：在投入语言模型训练前，以六类合成事件流、固定容量和可审计的 0/1 子目标损失验证 Oracle−FIFO 差距与效用可学习性。
- 通过线：0A 要求聚合差距至少 10 个百分点且至少四类任务存在 5 个百分点差距；0B 要求长度外推测试恢复至少 50% 的 Oracle−FIFO 差距。
- 限制：该阶段不证明自然语言事件编码可学，也不代表完整 Agent 任务上的收益。

## ADR-010：冻结效用巩固记忆 v2 的数学结构（现暂停）

- 状态：历史研究数学规范；当前不用于从零训练 Base，且不是实验证明。
- 决策：每条不可变事件由编码器产生有序潜在表示，模型预测有符号容量效用曲线 $\hat U_i(k)$；用 $S$ 条记录、$C$ 个活动向量双硬预算和资源价格 $\lambda$ 联合分配 $r_i$。满槽时恰好整体淘汰一条，其余记录可以扩张或压缩表示。
- 训练：效用由决策后未来损失的条件反事实定义；主干和事件编码器接受正常语言模型梯度，选择器接受停止梯度的效用曲线监督，离散动态规划动作不反向传播。
- 推理：只用当前可见信息预测曲线，以确定性多选背包动态规划优化**可加代理目标**；原生主干的少数层通过记忆 Cross-Attention 读取活动向量。
- 边界：v1 是 $R_{\max}=1,C=S,\lambda=0$ 的特例；不声称预测器已解决跨记录关系，也不声称代理目标等于真实未来损失或全局最优策略。
- 规范：[效用巩固记忆 v2](utility-consolidation-memory-v2.zh.md)。

## ADR-011：冻结 v2-A 首轮选择器配置（现暂停）

- 状态：历史实验候选；因旧记忆架构暂停而暂不实施，不锁定当前约 1B Base。
- 决策：竞争集合使用 **2 层 SetEncoder，隐藏宽度 384**。输入按事件组织，每条事件先映射为一个 384 维特征；两层集合自注意力让各事件在当前目标和近期上下文条件下交互。
- 输出：每条竞争事件产生四个**有符号实数** $\hat U_i(1),\hat U_i(2),\hat U_i(3),\hat U_i(4)$，分别预测该事件分配 1、2、3、4 个 latent 向量时的条件未来损失收益；另定义 $\hat U_i(0)=0$。这些数不是概率、不是四个记忆向量，也不是独立的保留/淘汰动作。
- 决策边界：选择器只负责预测曲线；实际 $r_i$ 由 v2 的 $S/C$ 硬预算动态规划联合决定。选择器不能读决策后的 $Y_t$。
- 待验证：两层是否足以表示跨事件关系、预测曲线是否校准；后续可消融层数和宽度，但必须标明偏离此首轮冻结配置。

## ADR-012：当前 Base 选用 Gated DeltaNet 混合注意力

- 状态：已接受为当前从零训练方向；第一版约 1B 数值配置已冻结，见 [Base-1B-v1 架构](base-1b-v1-architecture.zh.md)。以下“3:1 待测”是本 ADR 的历史表述，不再表示首版仍待选型。
- 决策：只训练文本 Base；线性序列混合层选 Gated DeltaNet（GDN），与周期性全局 GQA 注意力层组成混合主干。3:1 是待测首个层比例，不作为未经实验的最优性结论。
- 排除：首版不接入旧事件记忆、SetEncoder、效用教师、动态规划、视觉塔或 MoE；不加载 Qwen3.8-27B 权重。
- 后续：先统计候选配置参数量，并在 L40 实测数值稳定性、训练/生成吞吐和断点恢复，再冻结 tokenizer、层数、宽度、上下文长度及正式预训练预算。
- 依据：[Qwen3.8-27B 官方配置](https://huggingface.co/Qwen/Qwen3.8-27B/blob/main/config.json)展示同系 GDN/全注意力混合主干；本项目借鉴模块，不复制大模型尺寸或多模态结构。

## ADR-013：冻结第一版 Base-1B-v1

- 状态：已接受；meta 实例化参数量 1,005,213,696 已核对；目标尺寸 GPU 训练验收待做。
- 决策：32 层、宽 1536、FFN 4096，`[GDN, GDN, GDN, GQA] × 8`；GQA Q16/KV4/head96；GDN K16/V16/head96/卷积核4；共享 32k embedding；训练从 4096 上下文起步。
- 原因：停止为未经验证的架构细节消耗周期，将主要资源转到高质量数据与训练配方。该冻结不声称架构优越性。
- 配置与边界：[Base-1B-v1 架构](base-1b-v1-architecture.zh.md)、`configs/gdn/base_1b_v1.json`。
