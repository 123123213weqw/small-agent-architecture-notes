# 整体架构研究记录：原生主干、编码选择器与有界事件记忆（v2 前草案）

> 状态：**旧记忆研究草案，当前暂停**，不是现在从零训练的 GDN＋GQA Base。旧研究内部的 v2 公式见[效用巩固记忆 v2](utility-consolidation-memory-v2.zh.md)；本文第 1 节描述的是 v1 特例。
>
> 本文区分：①已冻结的记忆决策数学；②B2 已实现但未通过困难泛化测试的编码器；③拟从零训练的原生模型结构。旧实验文档保留原始记录，不用一次负面实验改写核心公式。

## 一句话定义

模型用普通因果注意力处理当前片段及近期 KV；另外保存最多 $S$ 条**独立、不可变、可逐条删除**的旧事件。编码器在每次单候选竞争时预测各条记录的未来删除成本；主干在后续 token 上通过其内部的记忆 Cross-Attention 读取保留记录。编码选择与内容读取是两个不同的问题。

```text
事件流 ──近期上下文/普通 KV──────────→ 自回归主干 ──→ 下一 token / 工具调用
   │                                      ↑
   └─等待 D─→ 单候选 c_t ─→ 编码器＋集合评分 ─→ 有界 M_t ─→ 主干内部记忆注意力
                              ↑                  │
                    训练期未来反事实标签          └─只在容量超限时删除一条
```

## 1. 当时已冻结的 v1 记忆决策数学（现为 v2 特例）

设 $M_t$ 为当前长期记录集合，$|M_t|\le S$；$B_t$ 是决策时仍可见的近期上下文；$g_t$ 是当前目标；$c_t$ 是事件发生后等待 $D$、刚到巩固点的单个候选。记录有稳定 event ID，内容不合并、不软写入。

$$
\mathcal R_t=M_t\cup\lbrace c_t\rbrace,
\qquad |\mathcal R_t|\le S+1.
$$

训练期用固定或缓慢 EMA 更新的模型 $\bar\theta$，在**决策之后**的未来 $Y_t=x_{t+1:t+F}$ 上产生删除成本：

$$
u_{t,i}=
\mathcal L_{\bar\theta,F}
\left(Y_t\mid B_t,\mathrm{mask}_i(\mathcal R_t)\right)
-
\mathcal L_{\bar\theta,F}
\left(Y_t\mid B_t,\mathcal R_t\right).
$$

$\mathrm{mask}_i$ 只隐藏第 $i$ 条记录，不改变其他记录内容和位置。正效用表示删除会增大未来损失；负效用表示删除反而有利。未来 $Y_t$ **只可用于训练标签**，不能进入推理期预测器输入。

预测器依据决策时可见信息估计 $\hat u_{t,i}$：

$$
\hat u_{t,i}=f_\phi(m_i,g_t,B_t,\mathcal R_t).
$$

未满容量时 $M_{t+1}=\mathcal R_t$；否则只淘汰一条：

$$
M_{t+1}=\mathcal R_t\setminus
\lbrace\arg\min_i\hat u_{t,i}\rbrace.
$$

若使用**真实** $u_{t,i}$，上述 $\arg\min$ 与“当前这一次删除后未来损失最小”严格等价，因为完整集合损失对所有候选相同。它不保证连续多次贪心淘汰全局最优，也不保证 $f_\phi$ 能预知具体未来。

## 2. 已实现的选择编码器：B2 原型，不等于最终 1B 定型

B2.1–B2.4 的实际实现并非凭单条规则直接删除，而是**编码后联合比较**。共享字节级 Transformer 分别编码每条记录与目标/近期上下文：

$$
h_i=E_\phi(m_i),\qquad h_g=E_\phi(g_t,B_t).
$$

实际实验把 $h_i,h_g$、新候选标记及若干元数据融合成 $z_i$，再让整个竞争集合交互：

$$
(\tilde z_1,\ldots,\tilde z_{S+1})
=\mathrm{SetEncoder}_\phi(z_1,\ldots,z_{S+1}),
\qquad
\hat u_i=\mathrm{Score}_\phi(\tilde z_i).
$$

这就是抽象公式 $f_\phi$ 的**一个具体实现**。已跑过的 C 配方使用回归与集合内排序，$L_{\mathrm{reg}}+0.5L_{\mathrm{rank}}$；B2.4 还比较了更深的集合编码器与更宽的模型。编码器预测的是各记录的**单步删除成本**，不是直接求全时域最优记忆子集。

需要正面承认两个状态差异：

- v1 核心规范排除了**显式年龄作为最终机制**，但 B2 诊断模型实际加入了相对年龄、event index、来源等 embedding。它们是实验性特征，不能未经消融就写成最终架构已冻结的必要组件。
- v1 理论允许 $u_{t,i}\lt0$；B2 实现以 `sigmoid` 输出 $[0,1]$，对应当时的非负合成标签。未来使用真实语言模型损失差时必须重新确认输出范围，不能把该实现原封不动当成通用效用预测器。

证据边界：B2.1 C 在六类合成任务的多种子确认中优于 Pointwise，但 `relation_chain` 退化；B2.4 的高干扰关系链仍失败；B2.7 将已有 DeepSet checkpoint 接到冻结 Reader 后，未能保全关键旧边。因此**“编码器已经选出最优记忆”尚未成立**。详见 [A/C 结果](../results/phase0_b21_ac_seeds/RESULTS.md)、[B2.4 结果](../results/phase0_b24/RESULTS.md)、[B2.7 接入](phase0-b2.7-predictor-reader.md)。

## 3. 拟从零训练的模型主干：功能结构已明，具体主干未锁定

拟采用一条自回归主干处理当前片段和近期 KV，长期记录通过**主干层内**标准 Cross-Attention 读取，而不是冻结 Qwen 后仅在末端接一个 Reader。令 $H$ 为某层当前 token 的隐状态，$V_\theta(M_t)$ 为已保留记录的可读取表示：

$$
Q=HW_Q,\qquad
K=V_\theta(M_t)W_K,\qquad
V=V_\theta(M_t)W_V,
$$

$$
H'=H+
\mathrm{softmax}\left(\frac{QK^\top}{\sqrt{d_m}}\right)VW_O.
$$

这里 $E_\phi$ **用于决定留什么**，$V_\theta$ 和主干注意力**用于使用留下的内容**。二者是否共享词嵌入或部分编码层是待比较的实现选择，不能从当前独立 B2 编码器或外挂 Reader 实验推定。旧记录的原始内容保持不可变；具体缓存向量可随训练权重重算，推理期可缓存。

目前**尚未冻结**：主干为普通/局部 Transformer 还是混合注意力、层数和宽度、记忆读取层位置、记录粒度与编码维度、$W/S/D/F$、位置处理、选择编码器是否与主干共享参数。若比较从零训练架构，A/B 必须从相同主干数学和初始化出发，不能把现成 Qwen 的全因果注意力悄悄替换成另一种局部注意力后仍称作“同一 Base”。

## 4. 训练与推理必须遵守同一时间线

1. 当前片段只读取**此时已保留**的 $M_t$ 与近期上下文，不得读取未来。
2. 候选等固定 $D$ 后才进入 $\mathcal R_t$；多个候选按确定顺序逐个处理、逐次重新评分。
3. 主干/记忆读取接受正常下一 token 或任务损失。只有它确实会使用记忆后，才让固定/EMA 教师在决策后 $F$ 区间计算反事实 $u_{t,i}$。
4. 选择编码器用反事实标签训练；是否沿用 B2 的 $0.5L_{\mathrm{rank}}$ 作为辅助项需预注册。Hard eviction 本身不通过普通反向传播求梯度。
5. 推理期没有 $Y_t$、教师分支或反向传播；只运行编码评分、一次硬淘汰，之后由主干读取 $M_{t+1}$。

对 $S+1$ 条记录计算全部精确标签，需要完整集合及各单记录 mask 的多次未来评估；标签采样、缓存和刷新频率是工程变量，训练 FLOPs 必须计入总成本。

## 5. 什么实验才有资格支持最终架构

从零训练的受控 A/B 应保持数据、tokenizer、主干数学、数据顺序、优化器与训练 token 一致，并报告参数、训练 FLOPs、近期 KV＋长期记忆的**实际字节数**和推理延迟。

| 条件 | 作用 |
|---|---|
| 同主干、无长期记忆 | 普通上下文能力与成本基线 |
| 同一记忆主干＋FIFO | 隔离原生记忆读取是否有效 |
| **同一记忆主干**＋编码器预测效用 | 检验实际在线选择策略 |
| **同一记忆主干**＋未来 Oracle | 仅作选择上界，不是可部署模型 |
| 足够长的全上下文 | 信息完整时的非等预算参考 |

先看 Oracle 记录是否能被原生主干读出，以及 Oracle 是否比同预算 FIFO 有收益；然后看预测策略能否稳定接近 Oracle。短任务、真实或接近真实的工具流、跨格式关系链和长度/容量外推须分开报告。只有信息保留、任务成功率和质量—成本曲线同时改善，才谈约 1B 的架构优势。不能拿不同权重的两个 Reader 直接比较策略，也不能把事后 Oracle 成绩当因果在线成绩。

## 6. 现有负面实验到底否定了什么

- [Phase 1 外挂 Reader](phase1-reader-v2-plan.zh.md)：冻结 Qwen 主干，仅训练末端 Cross-Attention；单记录混合训练种子敏感，混合八记录约随机。它**没有**训练本文件的原生主干、选择编码器或淘汰闭环，不能判定核心公式失败。
- [B2.7 编码器＋冻结 Reader](phase0-b2.7-predictor-reader.md)：现有独立选择编码器在特定困难关系链上没有保住关键证据。它确实否定“当前 checkpoint 已可直接部署”的说法，但不等于反事实效用定义无效。
- [基础预训练数据规划](base-pretraining-data-plan.md)：完整从零训练所需语料、来源许可和 tokenizer 尚需锁定；400 条审计样本不是预训练集。

## 7. 当时待确认的选择（以 v2 新规范为准）

1. 是否将“普通因果 Transformer 主干＋若干层内记忆 Cross-Attention”正式锁定为第一版**从零训练候选**，而把线性/混合主干留作后续对照。
2. 选择编码器是否沿用独立 $E_\phi+\mathrm{SetEncoder}$，以及哪些 B2 元数据允许进入最终版本；尤其要解决显式年龄与 v1 规范的冲突。
3. 真实未来损失可能为负时，效用输出头和监督目标如何定义；是否保留排序辅助损失。
4. 记忆读取表示与选择编码器是否共享参数、每条记录保留多少向量、在哪些层读取。
5. 从零 A/B 的首个规模、训练 token/数据版本与实际状态预算；未锁定这些前，不对最终 1B 性能作承诺。
